# Introduction:

This repository contains all working data, scripts, and documentation used to produce my capstone project for the M.S. Data Science degree. The aim is that the repo will demonstrate my ability to create reproducible research and documentation that can be shared and iterated on by other professionals. In order to achieve that, I will leverage the benefits of R's vast library of open source packages, quartos robust report formatting and typsetting capabilities, and Git's version managemnt paradigm all from within the open source Positron IDE.

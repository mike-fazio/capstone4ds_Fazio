Methods

All data analysis and processing was performed using the R programming language [@r]. Environmental observation data was acquired from the EPA’s Water Quality Portal via the dataRetrieval r-package [@wqp_2026; @dataRetrieval2026]. Data QA/QC and preprocessing was completed utilizing the Tidyverse package and any spatially aware data processing was conducted using the package sf [@tidyverse; @sf]. All spatial data was projected to the NAD83(2011) / Florida North State Plane Coordinate System (EPSG:6440) with distances in meters, which minimizes spatial distortion in the study area.

Study Area

The study area for this project is the Pensacola Bay System which includes portions of Pensacola Bay, Escambia Bay, East Bay and Blackwater Bay. Boundaries of this study area were achieved by accessing Florida Department of Environmental Protection (FDEP) Waterbody IDs feature layer hosted on ArcGIS Online [@FDEP2005WBIDs]. Once retrieved, the dataset was filtered to include only relevant WBIDs (nine IDs in the 548 series) and then combined to create a singular study area polygon. Creating the study area polygon is an important first step as it was needed to extract relevant environmental data from much larger datasets in the coming data gathering. The study area was intentionally chosen in an attempt to match the previous study area applied in @Geselbracht2024.

Data Acquisition and Processing

Oyster occurrence data was acquired from the Florida Fish and Wildlife Commission’s GIS portal as polygons and converted to points using polygon centroids [@FWC2026Oysters]. Salinity, dissolved oxygen, temperature, turbidity, and chlorophyll-a observations were obtained from the Water Quality Portal using the ‘dataRetrieval’ package in R for all sites located within the PBS and collected within the 20 year period from 2005 to 2025 [@wqp_2026; @dataRetrieval2026]. Parameters were chosen based on relevance and representation in previous oyster habitat restoration studies [@LaPeyre2021; @Barnes2007; @Pollack2012; @Geselbracht2024]. Bathymetry data for the PBS was obtained from NOAA [@NOAA_2018]. Bottom sediment data and oyster recruitment data was obtained from the Pensacola and Perdido Bay Estuary Program although the data were first reported by @MacCauley2004 and @Arnold2017, respectively.

Water-quality Data Preprocessing

All water quality parameters were inspected to ensure comparable measurement units and analytical procedures and avoid combining different forms of similar analytes. The IQR screen was applied to each parameter using data from all months. Aggregation then used non-outlier observations from the warm season (May through October). Outliers were defined as follows. \[ \begin{aligned} \text{Outlier if } \quad x &< Q_{0.25} - 1.5(IQR) \\ \text{or} \quad x &> Q_{0.75} + 1.5(IQR) \\ \ \text{where } IQR &= Q_{0.75} - Q_{0.25} \end{aligned} \]

Observations were averaged within station and year, then the annual means were averaged within station. Station means were averaged within 2 km hexagonal bins clipped to the study area. Each bin was represented by a point on its surface. Stations with one usable observation were retained.

Environmental Prediction Rasters

Prior to use in the MaxEnt modeling framework, continuous prediction rasters were created for dissolved oxygen, salinity, turbidity, and water temperature using the Inverse Path Distance Weighting (IPDW) package in R [@IPDW_2023]. IPDW is a variant of Inverse Distance Weighting (IDW), which is a deterministic interpolation method that allows for the estimation of point values using the equation:

\[ V= \frac{\sum\limits^{n}_{i=1} v_i {d^{-p}_{i}}}{\sum\limits^{n}_{i=1} {d^{-p}_{i}}} \]

where \(d\) is the distance between the prediction and measurement points, \(v_i\) is the parameter value, and \(p\) is a power parameter. However, in IPDW \(d\) is a calculated path-distance value rather than a typical Euclidean distance as used in IDW [@Stachelek2015].

IPDW was selected due to the model’s ability to be barrier aware and avoid interference or influence from crossing land boundaries that can be introduced when using more traditional Euclidean based interpolation methods [@Stachelek2015]. This is especially important given the geography on PBS where the Garcon Point area is a narrow, low lying peninsula separating Escambia Bay to the west and Blackwater Bay to the east. Both of which are significantly influence by different riverine inputs. Instead, IPDW weighs observations according to the shortest water-path distance through the aquatic environment.

Model sensitivty was evaluated for distance power and max interpolation range for each parameter. In IPDW, distance power determines how rapidly a site’s influence decays as path distance increases. The tested powers (\(p\)) were 0.25, 0.50, 0.75, 1.00, 1.25, 1.50, 2.00, 2.50, and 3.00. The tested ranges were 5, 10, 15, and 20 km. All combinations were evaluated for each parameter.

Spatial cross-validation was used to determine interpolation accuracy using the blockCV package in R, which uses spatial folds to split data into test and training data sets [@Valavi2019]. To assess sensitivity to the spatial split, the fold-generation procedure was repeated, each time refitting the IPDW model and comparing the results to the held-out observation spatial-blocks. For this analysis 5 spatial folds were used with 5 km spatial blocks, and blocks were assigned the folds randomly. This process was then repeated across 5 random seeds in which a new spatial partition was generated for each seed. For each spatial fold, the monitoring locations were used in the training data to construct the IPDW prediction surface. Withheld monitoring locations were used to extract predicted values from the prediction raster and compared to the observed station means.

Finally, model performance was evaluated using calculated prediction-error statistics for each distance power - max range combination. Each statistic was summarized across each repetition to generate a mean absolute error (MAE), the standard deviation of the MAE, the mean root mean squared error (RMSE) and its standard deviation, the mean prediction bias (+/-) and finally the prediction coverage. Mean MAE was the primary metric used in parameter selection, although in cases where differences between several of the lowest results were negligible, the smoother surfaces were given preference to better reflect the reality of a well mixed natural system.

The final prediction surfaces were generated by fitting the IPDW algorithm using the selected distance power and range on the full dataset for each environmental variable. The selected settings were evaluated using 5 km spatial blocks and five folds to calculate MAE, RMSE, prediction bias, and prediction coverage.

Species Distribution Model

Oyster occurrence data had to go through some processing prior to being used in the MaxEnt model. To avoid introducing unwanted spatial bias in the model, the original 443 processed occurence locations were spatially thinned to 1 km per point using the GeoThinneR package [@GeoThinneR]. MaxEnt also requires the use of background data, which are points who’s locations characterize available environmental conditions without being treated as oyster absences [@Phillips2006; @Elith2011; @Phillips2009]. For this study, 10,000 background points were randomly generated in areas that had complete prediction raster coverage, excluding any cells that already contained a presence location.

The final environmental predictors used were dissolved oxygen, salinity, sediment, turbidity, water temperature, and oyster recruitment. Sediment was treated a a factor with codes 1, 2, and 3, representing mud, silt, and sand; respectively.

The species distribution model was fit, tuned and evaluated using the ENMeval package in r (@Kass2021). A presence-background MaxEnt framework was used via the “maxnet” algorithm included in said package. Final predictors used in model fitting were depth, dissolved oxygen, salinity, sediment, turbidity, water temperature, and oyster recruitment. Sediment was the only categorical variable. The prediction domain was reduced to include areas that had a prediction cell value for each of the prediction variables. To avoid introducing spatial bias into the model, occurrence points were thinned to include only one point per 1km. 5,000 background points were randomly sampled from complete prediction cells that did not have an occurrence point.

Spatial cross-validation was performed using ENMeval’s included four-partition block method. This method evenly divides occurrences by northing, then easting, and finally assigns background points to each of the blocks. Four model candidates were evaluated for performance with increasing complexity using different combination of regularization techniques: linear (L), quadratic (Q), hinge (H), and interactions (P) Table 2. The four combinations used were L, LQ, LQH, and LQHP, with six regularization multipliers each 0.5, 1, 1.5, 2, 3, and 4. Overall, this resulted in 24 total model candidates and 96 fold evaluations.

Model validation was done using leave-one-out partitioning, repeating until every partition had been withheld. Each model was evaluated by calculating validation AUC against background points within the held-out region, validation at 10% training omission, AICc, and the number of non-zero coefficients.

The final model selection by filtering each candidate through a series of sieves. First, priority was given to models with a \({\Delta}AICc \le 2\). Then lowest omission, highest AUC, and fewest coefficients. If none met all the previous criteria, then all candidate with finite validation metrics were considered. Finally, the selected model was fit to all oyster occurrence and background data points to generate the final suitability raster.

HSI vs MaxEnt Comparison

A modified habitat suitability index (HSI) was created using similar methods presented in @Geselbracht2024. The data and methods used were based on a PPBEP adaption of the original HSI. Original input data was able to be obtained from PPBEP unfortunately the exact HSI model was no longer available so it had to be recreated using their provided methodology. The HSI was created using ArcGis Pro Suitability Modeler, with the inptu rasters transformed into suitability scores and subsequently combined using percentage weights. Environmental data used included salinity, temperatuer, dissolved oxygen, chlorophyll-a, and turbidity, with only observations collected between May through October in the years 2017 - 2023. It should be noted that this data was provided as-is and as such, should not be considered equal to the previously created environmental rasters in this study. The HSI also included the same sediment and larval dispersal data used here. Finally, the model included 2021 oyster distribution data, though it is not confirmed whether it is the same dataset obatained earlier in this study. Each variable was rated from 1 through 10, with all variables recieving a 1, 5 or 10. Where 1 = low, 5 = moderate, and 10 = high. The HSI was projected to align with the MaxEnt raster surface, grid cells were resampled to 100m using bilinear resampling. A coverage mask was created to ensure only cells that had values within both rasters were used in the comparison. Finally, the rasters were classified using equal intervals using breaks 0, 0.20, 0.40, 0.60, and 1.

Classified prediction raster agreement was described by determining the count of cells of exact agreement, the count of cells in psuedo-agreement (i.e. those that fell within one class), and finally by utilizing continuous Spearman correlation. Additionally, spatial agreement was evaluated mathematically by subtracting the values of the HSI from the values of the MaxEnt prediction surfaces, where;

\[ \begin{aligned} \text{MaxEnt Favorability} : i_{jk} \le 0 \\ \text{Model Agreement} : i_{jk} = 0 \\ \text{HSI Favorability} : i_{jk} \ge 0 \end{aligned} \]
